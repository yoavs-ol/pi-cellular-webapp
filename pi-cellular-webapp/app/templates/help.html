AT Command Reference

Modem Information

CommandDescriptionExample
ATTest AT response→ OK
AT+CGMIManufacturer→ Quectel
AT+CGMMModel→ RM520N-GL
AT+CGMRFirmware version→ RM520NGLAAR03A03M4G

SIM Management

CommandDescriptionExample
AT+CPIN?SIM status→ +CPIN: READY
AT+QUIMSLOT?Query active SIM slot→ +QUIMSLOT: 1
AT+QUIMSLOT=1Switch to SIM slot 1→ OK
AT+QUIMSLOT=2Switch to SIM slot 2→ OK

Network Operations

CommandDescriptionExample
AT+COPS?Current operator→ +COPS: 0,0,"OneLayer",7
AT+CEREG?LTE registration status→ +CEREG: 0,1
AT+C5GREG?5G registration status→ +C5GREG: 0,1
AT+QCSQSignal quality→ +QCSQ: "NR5G-SA",45,30,15,30
AT+QENG="servingcell"Serving cell info (band, RSRP, etc.)See manual

Data Connection

CommandDescriptionExample
AT+CGDCONT?PDP contexts→ List of APNs
AT+CGDCONT=1,"IPV4V6","pdn-1"Set APN→ OK
AT+CGCONTRDPActive PDP context→ Shows assigned IP

USB Network Modes

CommandDescription
AT+QCFG="usbnet",0QMI/NDIS (recommended for Linux)
AT+QCFG="usbnet",1ECM (recommended for Linux)
AT+QCFG="usbnet",2MBIM (Windows only)
AT+QCFG="usbnet",3RNDIS (Linux OK)

Power Control

CommandDescription
AT+CFUN=0Minimum functionality (radio off)
AT+CFUN=1Full functionality (radio on)
AT+CFUN=1,1Reboot module
AT+QPOWD=1Power down module (requires power cycle to restore)

RAT Preferences

CommandDescription
AT+QNWPREFCFG="mode_pref",AUTOAuto (5G/LTE/WCDMA)
AT+QNWPREFCFG="mode_pref",NR5G5G only
AT+QNWPREFCFG="mode_pref",LTELTE only
AT+QNWPREFCFG="nr5g_band"Query 5G bands
AT+QNWPREFCFG="lte_band"Query LTE bands

Identity Management

CommandDescription
AT+EGMR=0,7Read current IMEI
AT+EGMR=1,7,""Write IMEI (requires module reboot)
