Troubleshooting Guide

  1. Check all 4 antennas are connected
  2. Verify SIM is inserted: AT+CPIN? → should return READY
  3. Check signal strength: AT+QCSQ
  4. Verify SIM slot: AT+QUIMSLOT?
  5. Check serving cell: AT+QENG="servingcell"

Send blind ATE1 to enable echo, then retry.

If still no response, check:

  • ls /dev/ttyUSB* shows ports ttyUSB0-3
  • User is in dialout group: groups
  • ModemManager is not holding the port: systemctl stop ModemManager
  • Try different baud rates (default: 115200)

Cause: USB power insufficient.

Fix: Connect external 5V/3A to EXT PWR on the HAT.

USB-only power causes brownouts during network attach (high current draw).

  1. Check USB: lsusb | grep 2c7c
  2. Check devices: ls /dev/ttyUSB* /dev/cdc-wdm*
  3. Restart ModemManager: systemctl restart ModemManager
  4. Check logs: journalctl -u ModemManager -f
  5. Verify USB mode: AT+QCFG="usbnet" → should be 0 (QMI)

  1. Check SIM slot: AT+QUIMSLOT? → should show slot 1 or 2
  2. Switch slot: AT+QUIMSLOT=1 or AT+QUIMSLOT=2
  3. Check SIM lock: AT+CPIN?
  4. Try different SIM card
  5. Check DIP switch on HAT (if applicable)

  1. Check registration: AT+CEREG? (LTE) or AT+C5GREG? (5G) → should return 0,1 or 0,5
  2. Verify APN: AT+CGDCONT? → check APN matches network
  3. Try manual connection: nmcli connection up cellular
  4. Check logs: journalctl -u ModemManager -u NetworkManager -f
  5. Try ECM mode: AT+QCFG="usbnet",1 (requires module reboot)

Cause: System clock not synced from cellular network.

  1. Check modem is registered: Dashboard shows operator + signal
  2. Click "Sync Clock" button on dashboard
  3. Check logs: kubectl logs deployment/cellular-config | grep "Clock sync"

Requires privileged container (already configured).
